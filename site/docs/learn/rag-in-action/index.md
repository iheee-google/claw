## 新手执行策略

- 每章只做三件事：
  - 跑通 1 个最小示例
  - 记住 3~5 个关键词
  - 写 1 条“我今天真正搞懂了什么”
- 先不追求“最优参数”，先追求“可复现”。
- 卡住时优先记录报错 + 当前输入输出，再回头查。

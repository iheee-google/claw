# 新手剖析视角（为什么这样学）

## 你会在哪些地方卡住
1. **看懂目录但跑不起来**：缺环境、缺数据、缺入口脚本。
2. **跑起来但解释不清**：不知道 Retriever / Embedding / Rerank 各做什么。
3. **能改参数但不知道是否变好**：缺评估基线。

## 从零学习的顺序（强约束）
- 先树结构（系统地图）
- 再 00 模块跑通最小闭环
- 再补 01~04（数据到存储）
- 再做 05~08（效果优化）
- 最后 09~10（评估与进阶）

## 举一反三模板
- 我现在在哪个模块？
- 输入是什么？输出是什么？
- 这一步失败最常见报错是什么？
- 成功指标是什么？
